# CLUB // LAST ROUND

기획서 기반의 PvE 격투게임 플레이어블 프로토타입입니다.

## 실행

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.

## 구현된 핵심 루프

- 사무라이, 네크로맨서, 군인, S.W.A.T. 캐릭터 선택
- 4개 방으로 구성된 PvE 스테이지 진행
- 일반 적, 원거리 적, 방패 적, 돌진 적, 엘리트, 보스 AI
- 보스 HP 기반 3페이즈 전투
- HP와 방어 내구도 분리
- 플레이어/적 HP 수치 HUD 표시 및 적 처치 시 최대 체력의 8% 흡혈 회복
- 방어, 퍼펙트 방어(체력 회복 및 방어도 10% 회복), 방어 파괴 후 10초 대기 및 초당 최대치의 20% 자동 회복
- 스태미나, 마나, 궁극기 게이지
- 캐릭터별 스킬과 궁극기
- 네크로맨서 성장형 마나 루프: 시작 마나 0, 지팡이 적중 +1, 처치 +10
- 네크로맨서 지팡이 후리기, 마나 소모형 손 소환, 시체 소환, 망자의 속박, 영역 넓히기
- 콤보, 누적 피해량, 처형과 실행 보상
- 창고 전장과 가구 집기/타격 상호작용
- 방 클리어 경험치, 골드, 레벨업 및 능력치 성장

## 조작

### Player 1

`WASD` 이동 · `Space` 점프 · `F` 약공격 · `G` 강공격 · `H` 방어 · `J` 회피 · `K` 스킬 · `I` 망자의 속박(네크로맨서) · `L` 궁극기

### PvE 시스템

- `E` 처형: 적 HP 18% 이하에서 사용
- `Q` 환경물: 가까운 상자/의자를 공격해 적에게 피해
- 게임 중 `Esc`로 메뉴 열기/닫기, `R` 키로 타이틀 화면으로 복귀

난이도는 EASY, NORMAL, HARD, NIGHTMARE를 제공합니다.
